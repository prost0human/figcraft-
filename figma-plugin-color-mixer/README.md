# Lightroom Color Mixer — Figma Plugin

Профессиональный плагин для Figma, добавляющий возможности цветокоррекции в стиле Adobe Lightroom:
- **Баланс белого и тон:** Temp (цветовая температура), Tint (оттенок), Vibrance (красочность), Saturation (общая насыщенность).
- **Color Mixer (HSL):** 8 раздельных цветовых каналов (*Red, Orange, Yellow, Green, Aqua, Blue, Purple, Magenta*) со сдвигом цветового тона (Hue), насыщенности (Saturation) и яркости (Luminance).
- **Быстрые фото-пресеты:** *Warm Sunset*, *Cool Film*, *Vivid Landscape*, *Moody Teal*, *Clean Portrait*.
- **Сравнение до/после:** кнопка *Hold: Original* для моментального сравнения с оригиналом.
- **Недеструктивное редактирование:** плагин сохраняет настройки и оригинальный хеш изображения в `pluginData` слоя, позволяя вернуться к редактированию или нажать *Revert* для отката.

---

## 📦 Как установить плагин в Figma

1. **Скачайте и распакуйте архив:**
   Распакуйте архив `figma-color-mixer-plugin.zip` в любую удобную папку на компьютере (например, в `Documents/FigmaPlugins/color-mixer`).
   Внутри папки должны лежать:
   - `manifest.json`
   - `code.js`
   - `ui.html`

2. **Откройте приложение Figma:**
   * Откройте десктопное приложение Figma (или Figma в браузере в режиме разработчика).
   * Откройте любой файл или создайте новый.

3. **Импортируйте плагин:**
   * Нажмите на главное меню Figma (логотип в левом верхнем углу) ➔ **Plugins** ➔ **Development** ➔ **Import plugin from manifest…**
     *(Либо в правом клике по холсту: Plugins ➔ Development ➔ Import plugin from manifest…)*.
   * В открывшемся окне выберите файл **`manifest.json`** из распакованной папки.

4. **Готово!**
   Плагин появится в вашем меню **Plugins ➔ Development ➔ Lightroom Color Mixer**.

## 🎨 Как пользоваться плагином

1. Выберите на холсте любой слой с изображением (картинку, прямоугольник или фрейм с Image Fill).
2. Запустите плагин: **Plugins ➔ Development ➔ Lightroom Color Mixer** (или через быстрый поиск `Cmd + /` / `Ctrl + /` ➔ введите *Lightroom Color Mixer*).
3. В окне плагина:
   * Выберите готовый пресет в верхней строке либо настройте ползунки вручную.
   * Регулируйте **Temp** и **Tint** для настройки баланса белого.
   * Настройте **Vibrance** для мягкого усиления приглушенных цветов.
   * Выбирайте кружочки каналов в секции **Color Mixer** (*Red, Orange, Yellow, Green, Aqua, Blue, Purple, Magenta*) и вращайте слайдеры **Hue**, **Saturation**, **Luminance** для точечной настройки выбранного цвета.
   * Двойной клик по любому ползунку сбрасывает его значение в `0`.
   * Зажмите кнопку **Hold: Original**, чтобы увидеть фото до изменений.
4. Нажмите кнопку **Apply to Figma** — новое скорректированное изображение моментально применится к выбранному слою.
